# Northline — Freight & Dispatch

A responsive transportation website portfolio concept by Sami Ibrahim, designed for a 26 ft box truck owner-operator offering carrier and freight dispatching services.

## Features

- Dedicated service sections for shippers, freight brokers, and independent carriers
- Box truck, hot shot, and flatbed equipment selector
- Mobile navigation and responsive layouts
- Expandable FAQs
- Inquiry form with client-side validation and a local preview
- Semantic HTML, CSS, and vanilla JavaScript; no build step or dependencies

## View locally

Download this repository and open `index.html` in a browser. An internet connection loads Google Fonts and the Unsplash background image.

## Publish with GitHub Pages

1. Open this repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/ (root)**, then save.
4. GitHub will display the live website URL when deployment completes.

## Demo limitations

This is an illustrative portfolio concept, not a verified operating transportation business or a client endorsement. Northline is a sample brand. The inquiry form previews information only: it does not send, store, or book anything. Production use requires verified business details and an email or CRM integration. No client references or operating credentials are claimed.

## Assets

Typography: Barlow Condensed and DM Sans via Google Fonts. Industry photograph served from Unsplash. Review external asset licensing and availability before production use.
